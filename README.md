# 基金理财研究

A 股红利策略基金的年化收益、规模与费率对比。收益按复权净值计算、含分红再投资，年化为几何年化。

> 仅作数据梳理，不构成投资建议。

## HTML 阅读

入口：[doc/index.html](doc/index.html)

直接用浏览器打开 `doc/index.html` 即可，包含目录页、响应式表格和打印样式。HTML 由 Markdown 生成，修改文档后需重新生成：

```bash
python3 -m venv tmp/.venv
tmp/.venv/bin/pip install -r tmp/requirements.txt
tmp/.venv/bin/python tmp/build_doc.py
```

> 如果使用 Homebrew Python（受 PEP 668 限制），不要直接 `pip install`，使用上面的 `tmp/.venv`。

## 数据口径

- 收益数据截至：**2026-10-16**
- 规模数据截至：**2026-06-30**（最近季报）
- 收益：复权净值，含分红再投资
- 年化：`(1 + 区间累计收益率)^(1/年数) − 1`，几何年化，不是区间收益加总
- 费率：管理费 + 托管费，不含申购费、销售服务费
- 范围：A 股红利产品；不含港股通/恒生红利、QDII、主动管理型红利基金、消费红利等行业主题

数据来源：天天基金/东方财富基金档案、中证指数公司。
