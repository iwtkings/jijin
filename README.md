# 基金理财研究

A 股红利策略基金与固收+基金的年化收益、规模与费率对比，以及基金经理的评定方法。收益按复权净值计算、含分红再投资，年化为几何年化。

> 仅作数据梳理，不构成投资建议。

## 数据口径

- 收益数据截至：**2026-10-16**
- 规模数据截至：**2026-06-30**（最近季报）
- 收益：复权净值，含分红再投资
- 年化：`(1 + 区间累计收益率)^(1/年数) − 1`，几何年化，不是区间收益加总
- 波动率：近 3 年日收益率的年化标准差；最大回撤：近 1 年
- 费率：管理费 + 托管费，不含申购费、销售服务费
- 范围：A 股红利产品与固收+（二级债基、偏债混合）；不含港股通/恒生红利、QDII、主动管理型红利基金、消费红利等行业主题、可转债主题基金
- 方法论：主动权益、固收+、指数增强等以“人”为主要变量的产品适用；纯被动指数基金、货币基金不适用于经理评定

数据来源：天天基金/东方财富基金档案、中证指数公司。
