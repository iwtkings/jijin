固收+基金年化收益排行梳理（低波 / 中波 / 高波）

数据截至：2026-10-16
统计口径：按复权净值计算，含分红再投资；年化 = (1 + 区间累计收益率)^(1/年数) − 1，为几何年化；波动率 = 近 3 年日收益率的年化标准差；最大回撤为近 1 年。
规模截至：2026-06-30（最近季报）；费率 = 管理费 + 托管费，不含申购费、销售服务费。
范围：A 股人民币份额的二级债基与偏债混合基金（固收+ 主流口径）；剔除可转债主题、定开/持有期产品、规模 < 2 亿、成立不足 3 年；C/E 类不单独排名；近 3 年波动率 > 15% 视为实质权益仓位，不纳入。

一、先说结论

按“近 3 年年化”排序，先分档、再比收益：

  1. 低波（波动率 ≤ 3%）：汇添富添添乐双盈债券A（017592） 近 3 年年化 6.43%，回撤仅 -0.98%，规模 122.4 亿；前海开源弘丰债券A（005138） 5.73%、蜂巢恒利债券A（008035） 5.48% 次之。
  2. 中波（3%-6%）：国寿安保稳荣混合A（004279） 9.55%，近 5 年 5.98%；淳厚添益债券A（017498） 8.72%、汇添富双利增强债券A（000406） 8.51%。
  3. 高波（6%-15%）：工银聚享混合A（011729） 16.61%，但规模只有 2.1 亿；华夏永康添福混合A（005128） 13.98%、财通收益增强债券A（720003） 13.58%；规模与收益兼顾看 景顺长城景颐丰利债券A（003504）（235.9 亿，12.73%）。
  4. 档位决定风险收益：三档近 3 年年化中位数分别为 3.34% / 4.27% / 6.50%，近 1 年最大回撤也逐档放大；跨档比较收益没有意义。
  5. 近 3 年是顺风期：满 5 年的 272 只产品里，256 只（94%）近 3 年年化高于近 5 年，高波档 80 只里有 79 只如此。不要把 3 年数字线性外推。

一句话总结：

先按能承受的回撤选档，再在同档内挑收益、费率和规模。低波看 017592 / 005138 / 519753；中波看 004279 / 000406 / 006839；高波求弹性看 003504 / 720003 / 001751；大资金优先 002065 / 002969 / 003504。

二、分档与筛选口径

  • 初始池：天天基金分类中的“债券型-混合二级”与“混合型-偏债”共 3447 个份额，剔除 C/E/后端等重复份额后 1637 只。
  • 依次剔除：成立不足 3 年 491 只 → 规模不足 2 亿 648 只 → 名称含“转债/可转/定开/定期开放/封闭/持有” 148 只（其中持有期 101 只）→ 关键数据缺失 6 只，剩 344 只。
  • 再剔除近 3 年波动率 > 15% 的 9 只（如 202105 南方广利回报 15.2%、003877 富国久利 15.5%、501073 华安智联 19.8%），最终 335 只入样。
  • 分档：波动率 ≤ 3% 为低波（62 只），3%-6% 为中波（186 只），6%-15% 为高波（87 只）。
  • 每档按近 3 年年化取前 15 名；“近 5 年年化”只对成立满 5 年的产品计算，未满 5 年记“—”。

波动率取近 3 年、最大回撤取近 1 年，两个窗口不同，不能相互换算；波动率也测不出信用违约这类尾部风险。

七、为什么同为固收+，收益差这么多？

1. 仓位决定档位，不是“名字”决定档位

335 只产品近 3 年年化从 -3.80% 到 16.61%，波动率从 0.59% 到 14.74%。二级债基和偏债混合只是“壳”，真正的差异是股票、转债仓位和信用暴露。

2. 费率是确定损耗

费率区间 0.35%-1.40%，最高与最低相差 1.05 个百分点（001722 工银银和利 0.35% vs 002317 招商睿逸、008488 华商恒益 1.40%）。固收+ 年化只有 4%-8%，1 个百分点的费率占比很高，10 年复利下来差距约 10 个百分点。

3. 规模与弹性反向

高波前 3 名规模只有 2.1 亿、2.6 亿、24.5 亿；百亿级产品里，003504（12.73%）、001751（11.13%）、000143（10.18%）已经是“规模 + 收益”兼顾的少数。

4. 回撤不只看波动率

470010 近 3 年 8.40%，近 1 年回撤 -9.55%；006839 8.13%，回撤只有 -2.00%。低波档的 011897 波动率 2.88%，却出现 8.75% 回撤——波动率测不出信用尾部风险。

5. 近 1 年分化远大于 3 年

高波档近 1 年收益从 -13.39% 到 +22.44%，3 年榜把这种分化平均掉了；买之前至少要看一眼最近一年和最大回撤。

九、风险提示

  1. 固收+ 不是保本产品：债券久期、信用违约、转债估值、股票仓位都会带来回撤。
  2. 分档基于近 3 年波动率，风格漂移后档位会变，例如高波产品继续提高权益仓位。
  3. 近 3 年是顺风期，94% 的满 5 年产品“3 年 > 5 年”，不能把近 3 年收益当成长期能力。
  4. 规模数据截至 2026-06-30，之后可能变化；规模 < 5 亿的产品有清盘和流动性风险。
  5. 费率只含管理费 + 托管费，不含申购费、销售服务费；A/C 类实际持有成本不同。
  6. 历史收益不代表未来表现，本文仅作数据梳理，不构成投资建议。
