固收+基金年化收益排行梳理（低波 / 中波 / 高波）

数据截至：2026-10-30
统计口径：按复权净值计算，含分红再投资；年化 = (1 + 区间累计收益率)^(1/年数) − 1，为几何年化；波动率 = 近 3 年日收益率的年化标准差；最大回撤为近 1 年。
规模截至：2026-09-30（三季报）；费率 = 管理费 + 托管费，不含申购费、销售服务费。
范围：A 股人民币份额的二级债基与偏债混合基金（固收+ 主流口径）；剔除可转债主题、定开/持有期产品、规模 < 2 亿、成立不足 3 年；C/E 类不单独排名；近 3 年波动率 > 15% 视为实质权益仓位，不纳入。

一、先说结论

按“近 3 年年化”排序，先分档、再比收益：

  1. 低波（波动率 ≤ 3%）：汇添富添添乐双盈债券A（017592） 近 3 年年化 6.50%，回撤仅 -1.31%，规模 134.1 亿；前海开源弘丰债券A（005138） 5.79%、南方惠享稳健添利债券A（018772） 5.57% 次之。
  2. 中波（3%-6%）：国寿安保稳荣混合A（004279） 9.75%，近 5 年 5.96%；安信聚利增强债券A（006839） 8.61%、华商稳健双利债券A（630007） 8.13%。
  3. 高波（6%-15%）：华夏永康添福混合A（005128） 13.37%，但规模只有 2.2 亿；财通收益增强债券A（720003） 11.81%、华商稳定增利债券A（630009） 11.38%；规模与收益兼顾看 景顺长城景颐丰利债券A（003504）（206.0 亿，10.84%）。
  4. 档位决定风险收益：三档近 3 年年化中位数分别为 3.26% / 3.98% / 5.82%，近 1 年最大回撤也逐档放大；跨档比较收益没有意义。
  5. 近 3 年是顺风期：满 5 年的 271 只产品里，254 只（94%）近 3 年年化高于近 5 年，高波档 80 只里有 78 只如此。10 月下旬权益急跌后，高波档近 1 年回撤已经扩大到 -25.96%，不要把 3 年数字线性外推。

一句话总结：

先按能承受的回撤选档，再在同档内挑收益、费率和规模。低波看 017592 / 005138 / 519753；中波看 004279 / 000406 / 006839；高波求弹性看 003504 / 720003 / 001751；大资金优先 002065 / 002969 / 003504。

二、分档与筛选口径

  • 初始池：天天基金分类中的“债券型-混合二级”与“混合型-偏债”共 3468 个份额（1993 + 1475），剔除 C/E/后端等重复份额后 1664 只。
  • 依次剔除：成立不足 3 年 512 只 → 规模不足 2 亿 658 只 → 名称含“转债/可转/定开/定期开放/封闭/持有” 146 只（其中持有期 101 只、定开 26 只、转债 19 只）→ 关键数据缺失 0 只，剩 348 只。
  • 再剔除近 3 年波动率 > 15% 的 11 只（如 210014 金鹰元丰 25.98%、501073 华安智联 20.45%、003877 富国久利 15.76%），最终 337 只入样。
  • 分档：波动率 ≤ 3% 为低波（62 只），3%-6% 为中波（187 只），6%-15% 为高波（88 只）。
  • 每档按近 3 年年化取前 15 名；“近 5 年年化”只对成立满 5 年的产品计算，未满 5 年记“—”。

波动率取近 3 年、最大回撤取近 1 年，两个窗口不同，不能相互换算；波动率也测不出信用违约这类尾部风险。

七、为什么同为固收+，收益差这么多？

1. 仓位决定档位，不是“名字”决定档位

337 只产品近 3 年年化从 -1.47% 到 13.37%，波动率从 0.64% 到 14.32%。二级债基和偏债混合只是“壳”，真正的差异是股票、转债仓位和信用暴露。

2. 费率是确定损耗

费率区间 0.35%-1.40%，最高与最低相差 1.05 个百分点（001722 工银银和利 0.35% vs 002317 招商睿逸、008488 华商恒益 1.40%）。固收+ 年化只有 4%-8%，1 个百分点的费率占比很高，10 年复利下来差距约 10 个百分点。

3. 规模与弹性反向

高波前 3 名规模只有 2.2 亿、20.7 亿、46.0 亿；百亿级产品里，003504（10.84%）、001751（9.39%）、000143（9.24%）已经是“规模 + 收益”兼顾的少数。

4. 回撤不只看波动率

470010 近 3 年 7.77%，近 1 年回撤 -11.18%；006839 8.61%，回撤只有 -2.00%。低波档的 011897 波动率 2.93%，却出现 9.64% 回撤——波动率测不出信用尾部风险。

5. 近 1 年分化远大于 3 年

高波档近 1 年收益从 -12.39% 到 +19.16%，3 年榜把这种分化平均掉了；买之前至少要看一眼最近一年和最大回撤。
