阅读说明

  • 红利两篇口径不同：宽基红利不含红利低波，红利低波单独成篇；固收+按近 3 年波动率分低/中/高三档，不与红利混排。
  • 收益数据截至 2026-10-16，规模数据截至 2026-06-30；费率 = 管理费 + 托管费，不含申购费与销售服务费。
  • “近 3 年年化”是平均每年的复利年化，不是三年收益加总，也不是年度收益的算术平均。
